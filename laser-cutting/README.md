# Laser cutting

**Machine:** 20W diode laser, intended for wood and suitable acrylic.

## Active
- [NUT65 genuine walnut veneer accents](projects/nut65-veneer.md)
- [Clock OS and Govee walnut details](projects/clock-sensor-accents.md)

## Workflow
Start from actual measurements → draw parametric 2D outline → test in cardstock/thin scrap → cut small veneer sample to calibrate kerf → full part → test fit *dry* → prepare adhesive/finish and document results. Track grain direction, face orientation, cut settings, scorch and edge quality.

The laser is **not** for cutting aluminum or machining POM.
