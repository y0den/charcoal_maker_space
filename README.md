# Charcoal Maker Space

Central workshop knowledge base for custom fabrication: project plans, measured geometry, CAD/CAM workflows, tests, design decisions, and clean handoffs between chats.

**Organized by process, with cross-process projects linked from one project index.** This repository records *what was actually made and tested*, not just ideas.

## Workshop sections

| Section | Scope |
| --- | --- |
| [3D printing](3d-printing/README.md) | Bambu X1C, printed parts, prototypes, fixtures, fit tests |
| [CNC & precision routing](cnc-routing/README.md) | CNC research, handheld router sleds, hardwood and metal machining |
| [Laser cutting](laser-cutting/README.md) | 20W diode laser, veneer templates, wooden details, cut settings |
