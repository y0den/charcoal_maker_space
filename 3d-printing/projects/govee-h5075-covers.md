# Govee H5075 sensor covers

**Status:** Design idea; no measured CAD or print currently recorded.

- Intended as small matching black shells with thin laser-cut or machined walnut faces.
- Start from the actual H5075 exterior and keep openings clear for the sensing pathway; preserve battery access and usable buttons/display.
- Avoid tight, closed shells that bias temperature/humidity response.
- Fit-test in inexpensive filament before producing matching gift set.
- Record prototype height/width/depth, shell gap, magnet/clip mechanism if used, readings before and after.
- Main project: [Clock OS hardware](../../projects/clock-os-hardware.md).
