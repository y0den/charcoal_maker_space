# Clock OS ESP32 display enclosure

**Status:** Concept and fit planning. See [project hub](../../projects/clock-os-hardware.md).

- Designed for real 3.9-inch ESP32 display used by Charcoal Clock OS, not a guessed generic rectangular module.
- Preferred appearance: slim matte-black PLA with genuine walnut face or accent.
- Plan proper access to USB-C, display front, mounting points and any needed service controls.
- Candidate manufacturing: printed internal frame/back; laser-cut walnut veneer front; eventually CNC-machined hardwood front if warranted.
- Measurement needed: board outline, actual screen active area, port location, connector envelope, screw holes, heat/vent requirements.
- Test sequence: single-piece fit gauges → complete shell in test PLA → verify powered operation → cosmetic final.
