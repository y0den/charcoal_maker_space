# 3D printing

**Primary machine:** Bambu Lab X1 Carbon with AMS, 0.4 mm nozzle.

## Active projects
- [Clock OS display enclosure](projects/clock-os-enclosures.md)
- [Govee H5075 covers](projects/govee-h5075-covers.md)
- [DeWalt dust splitter coupler](projects/dewalt-dust-coupler.md)

## Workflow
Design → inspect geometry/assembled fit → small fit coupon where useful → slice in Bambu Studio → print in economical test filament → physically measure → iterate → final material.

Keep `source/`, `exports/`, `photos/`, `tests/` under a project when assets are first added. Note exactly which `.3mf` files contain slicer profiles versus geometry-only exports. Never label an unprinted tolerance revision as confirmed.
